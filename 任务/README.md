# 任务1_Agent工作流构建材料包

本目录为《任务 1：Agent 工作流构建》的官方原始材料包：

- [`任务1_Agent工作流构建_题目.md`](任务1_Agent工作流构建_题目.md)：完整题目与提交要求
- `data/`：商品库（`products.jsonl`）与公开模拟购物需求（`tasks.jsonl`）
- `starter/`：基础接口模板与模拟调用代码（`agent_interface.py` / `simulate_agent.py`）
- `requirements.txt`：材料包原始依赖清单

> 数据来源：[stockholmux/ecommerce-sample-set](https://github.com/stockholmux/ecommerce-sample-set)
> （CC BY-SA 3.0），材料包为其 96 商品 / 50 任务的种子抽样（seed=20260705）。
