# 任务 1：Agent 工作流构建

## 背景

Agent 系统需要根据用户目标自主规划步骤、调用工具、观察中间结果并完成任务。本题提供一个离线电商商品库和一组购物需求。你需要构建一个使用大模型的购物 Agent，使其能够理解需求、检索商品、判断约束并返回执行结果。

大模型必须使用，可以调用 API，也可以使用本地模型。模型选择、提示词设计、工具编排和失败处理方式由你自行决定。

## 任务

请基于材料包中的商品库和购物需求，制作一个可运行的购物 Agent 原型系统。系统的交互形式由你自行设计，可以采用命令行、Web 页面、API 或 Notebook 等形式。

系统应能够完成需求理解、商品搜索、候选比较、约束检查、购买决策和结果说明等主干功能。具体的系统架构、工具形式、对话状态管理和结果展示方式由你自行决定。

### 可选拓展方向

在完成主干功能的基础上，你可以根据兴趣选择实现多轮对话、主动追问、需求冲突处理、对话状态管理或决策解释等增强功能。例如，当用户需求信息不足时，Agent 可以主动追问，并根据后续输入更新购物决策。这些拓展功能不作强制要求。

## 数据集说明

材料包中的 `data/` 为总数据集，不提供训练集、验证集、测试集划分。

`products.jsonl`：商品库，每行一个商品对象。

- `product_id`：商品唯一 ID。
- `name`：商品名称。
- `item_type`：商品类型。
- `manufacturer`：制造商。
- `price`：商品价格。
- `tags`：商品标签列表。
- `description`：商品描述文本。

`tasks.jsonl`：公开模拟购物需求，每行一个任务对象。

- `task_id`：任务 ID。
- `instruction`：自然语言购物需求。

`starter/` 中提供了一份基础接口模板和模拟调用代码，可作为实现参考。你可以修改或重新设计系统接口和交互方式。
